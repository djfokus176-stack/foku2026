# ⚡ FOKU2026 — SP500 SIGNAL AI PRO (Master Edition v7)

Osobna, niezależna wersja bota S&P 500 (US500) z własnym archiwum (`archiwum_foku2026_sp500.json`), automatycznym zamykaniem w zysku, modułem Samo-Audytu AI, zegarem rynków światowych oraz powiadomieniami Telegram i Auto-Tradingiem DEMO Capital.com.

## Pliki w paczce:
- `app.py` — główny plik aplikacji (dla Streamlit Cloud)
- `foku2026.py` — kopia głównego pliku pod nazwą `foku2026.py` (jeśli chcesz dodać go obok starego `app.py` w tym samym repozytorium)
- `requirements.txt` — lista bibliotek wymaganych przez Streamlit Cloud
- `.github/workflows/foku2026_runner.yml` — automat 24/5 dla GitHub Actions
